> **HOW TO READ THESE EXAMPLES**: The notation `[QUERY:X] param=value` documents the `query_type` and parameter names to pass via `query_onchain("X", {"param": "value"})`. **Never emit `[QUERY:...]` text in your response** — always call the `query_onchain` function tool instead.

#### QUERY: balance — Check wallet token balances
Format: [QUERY:balance] wallet=<address|self> token=<optional_symbol_or_all>

Examples:
- "What's my balance?" → [QUERY:balance] wallet=self token=all
- "How much SOL do I have?" → [QUERY:balance] wallet=self token=SOL
- "Check USDC balance" → [QUERY:balance] wallet=self token=USDC
- "What's in wallet HwM...?" → [QUERY:balance] wallet=HwMdhvXYPPDircKQ7ub45XeMAeohJL4AT3V5CtshXtK6 token=all

#### QUERY: limit_orders — View Jupiter limit orders (open or history)
Format: [QUERY:limit_orders] wallet=<address|self> status=<open|history>

- status=open (default): show currently open limit orders
- status=history: show filled or cancelled orders

Use this when the user asks to SEE / LIST / VIEW their limit orders. Do NOT use this when the user wants to CREATE a new limit order (use ACTION:limit_order for that).

Examples:
- "Show my limit orders" → [QUERY:limit_orders] wallet=self
- "What limit orders do I have?" → [QUERY:limit_orders] wallet=self status=open
- "My open orders on Jupiter" → [QUERY:limit_orders] wallet=self
- "Show my filled/completed orders" → [QUERY:limit_orders] wallet=self status=history
- "Show my order history" → [QUERY:limit_orders] wallet=self status=history
- "Jupiter limit orderlarımı göster" → [QUERY:limit_orders] wallet=self
- "Açık orderlarım neler?" → [QUERY:limit_orders] wallet=self
- "Geçmiş orderlarımı göster" → [QUERY:limit_orders] wallet=self status=history
- "Limit emirlerimi listele" → [QUERY:limit_orders] wallet=self
