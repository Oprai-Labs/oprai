> **HOW TO READ THESE EXAMPLES**: The notation `[ACTION:X] param=value` documents the `action_type` and parameter names to pass via `execute_action("X", {"param": "value"})`. **Never emit `[ACTION:...]` text in your response** — always call the `execute_action` function tool instead.

## STREAMFLOW — TOKEN STREAMING & VESTING

Streamflow Finance is a token streaming and vesting protocol on Solana. It enables continuous, programmable token distribution: payroll, investor vesting, DAO grants, and recurring payments. Streams unlock tokens continuously or in discrete periods. Visit app.streamflow.finance to manage streams visually.

**Key concepts:**
- **period** — unlock interval in seconds (3600=hourly, 86400=daily, 604800=weekly, 2592000=monthly)
- **amountPerPeriod** — tokens unlocked each period (total ÷ number_of_periods)
- **cliff** — Unix timestamp; tokens locked until this date, then cliffAmount released
- **automaticWithdrawal** — tokens auto-sent to recipient each period (no manual claim needed)
- **canTopup** — sender can add more tokens to extend the stream duration at the same rate

---

### STREAMFLOW_CREATE — Create a single token stream or vesting schedule

Required: recipient, mint, amount, period, amountPerPeriod
Optional: start, cliff, cliffAmount, name, canTopup, cancelableBySender, cancelableByRecipient, transferableBySender, transferableByRecipient, automaticWithdrawal, withdrawalFrequency, partner, isNative

Examples:
- "Stream 1000 USDC to HwM...abc over 30 days (daily unlocks)"
  -> [ACTION:streamflow_create] recipient=HwM...abc mint=USDC amount=1000 period=86400 amountPerPeriod=33.33 name="Monthly salary"

- "Create a 12-month linear vesting for 100000 JUP to investor wallet, starting next month"
  -> [ACTION:streamflow_create] recipient=<wallet> mint=JUP amount=100000 period=2592000 amountPerPeriod=8333.33 start=<next_month_unix> name="Investor vesting"

- "Vest 50000 BONK to dev with 3-month cliff then monthly unlocks, 5000 BONK at cliff"
  -> [ACTION:streamflow_create] recipient=<wallet> mint=BONK amount=50000 period=2592000 amountPerPeriod=5000 cliff=<3_months_unix> cliffAmount=5000 name="Dev grant"

- "Set up weekly USDT payroll of 500 USDT to HwM...abc, auto-send each week"
  -> [ACTION:streamflow_create] recipient=HwM...abc mint=USDT amount=2000 period=604800 amountPerPeriod=500 automaticWithdrawal=true name="Weekly payroll"

- "Stream SOL to wallet, allow recipient to cancel, topup enabled"
  -> [ACTION:streamflow_create] recipient=<wallet> mint=SOL amount=10 period=86400 amountPerPeriod=0.333 cancelableByRecipient=true canTopup=true

- "Stream native SOL (not wSOL) to HwM...abc"
  -> [ACTION:streamflow_create] recipient=HwM...abc mint=SOL amount=5 period=86400 amountPerPeriod=0.166 isNative=true

### STREAMFLOW_CREATE_MULTIPLE — Batch-create streams to multiple recipients

Required: recipients (array), mint, period
Optional: start, cliff, canTopup, cancelableBySender, cancelableByRecipient, transferableBySender, transferableByRecipient, automaticWithdrawal, withdrawalFrequency, partner, isNative

Each recipient object: { recipient, amount, amountPerPeriod, name?, cliffAmount? }

Examples:
- "Create monthly USDC vesting streams for 3 team members: Alice 5000, Bob 3000, Carol 4000 USDC"
  -> [ACTION:streamflow_create_multiple] mint=USDC period=2592000 recipients=[{"recipient":"<alice_wallet>","amount":"5000","amountPerPeriod":"416.67","name":"Alice salary"},{"recipient":"<bob_wallet>","amount":"3000","amountPerPeriod":"250","name":"Bob salary"},{"recipient":"<carol_wallet>","amount":"4000","amountPerPeriod":"333.33","name":"Carol salary"}]

- "Batch vest 10000 JUP each to 5 contributors with weekly unlocks"
  -> [ACTION:streamflow_create_multiple] mint=JUP period=604800 recipients=[...each with amount=10000, amountPerPeriod=192.31...]

---

### STREAMFLOW_CANCEL — Cancel an active stream

Required: streamId

Examples:
- "Cancel my Streamflow stream ABC123..."
  -> [ACTION:streamflow_cancel] streamId=ABC123...

- "Stop the stream to HwM...abc"
  -> First call streamflow_list to find the streamId, then: [ACTION:streamflow_cancel] streamId=<found_id>

Note: Unlocked tokens go to recipient; locked tokens return to sender.

---

### STREAMFLOW_WITHDRAW — Withdraw unlocked/vested tokens

Required: streamId
Optional: amount (omit = withdraw all unlocked)

Examples:
- "Withdraw all unlocked tokens from stream ABC123..."
  -> [ACTION:streamflow_withdraw] streamId=ABC123...

- "Withdraw 500 USDC from my vesting stream ABC123..."
  -> [ACTION:streamflow_withdraw] streamId=ABC123... amount=500

- "Claim my vested tokens from stream XYZ..."
  -> [ACTION:streamflow_withdraw] streamId=XYZ...

---

### STREAMFLOW_TRANSFER — Transfer stream to new recipient

Required: streamId, newRecipient

Examples:
- "Transfer stream ABC123... to new wallet HwM...xyz"
  -> [ACTION:streamflow_transfer] streamId=ABC123... newRecipient=HwM...xyz

- "Change the recipient of my stream to HwM...xyz"
  -> [ACTION:streamflow_transfer] streamId=<from list> newRecipient=HwM...xyz

Note: Stream must have transferableBySender=true (set at creation).

---

### STREAMFLOW_TOPUP — Add tokens to extend stream duration

Required: streamId, amount

Examples:
- "Add 1000 USDC to my stream ABC123... to extend it"
  -> [ACTION:streamflow_topup] streamId=ABC123... amount=1000

- "Top up the salary stream with 500 more USDT"
  -> [ACTION:streamflow_topup] streamId=<from list> amount=500

Note: Stream must have canTopup=true. Tokens added extend at the same amountPerPeriod rate.

---

### STREAMFLOW_UPDATE — Update mutable stream parameters

Required: streamId
Optional: automaticWithdrawal, withdrawalFrequency, transferableBySender, transferableByRecipient

Examples:
- "Enable automatic withdrawal on stream ABC123..."
  -> [ACTION:streamflow_update] streamId=ABC123... automaticWithdrawal=true

- "Change auto-withdrawal frequency of stream ABC123... to weekly (604800 seconds)"
  -> [ACTION:streamflow_update] streamId=ABC123... withdrawalFrequency=604800

- "Disable transfer by sender on my stream"
  -> [ACTION:streamflow_update] streamId=<from list> transferableBySender=false

---

Required: streamId

Examples:
- "Show details of stream ABC123..."
  -> [ACTION:streamflow_get_one] streamId=ABC123...

- "What's the status of my Streamflow stream XYZ...?"
  -> [ACTION:streamflow_get_one] streamId=XYZ...

- "How much is left in stream ABC123...?"
  -> [ACTION:streamflow_get_one] streamId=ABC123...

---

### STREAMFLOW_LIST — List all streams for connected wallet

Required: none (uses connected wallet automatically)
Optional: direction — filter by stream role: "incoming" (recipient), "outgoing" (sender), "all" (default)

Examples:
- "Show my Streamflow streams"
  -> [ACTION:streamflow_list]

- "List all my vesting schedules"
  -> [ACTION:streamflow_list]

- "What streams am I receiving?"
  -> [ACTION:streamflow_list] direction=incoming

- "Show streams I'm sending to others"
  -> [ACTION:streamflow_list] direction=outgoing

- "List only the vesting streams where I'm the sender"
  -> [ACTION:streamflow_list] direction=outgoing

- "What tokens am I receiving via Streamflow?"
  -> [ACTION:streamflow_list] direction=incoming

- "Streamflow'daki streamlerimi göster"
  -> [ACTION:streamflow_list]

- "Hangi streamleri alıyorum?"
  -> [ACTION:streamflow_list] direction=incoming

- "Gönderdiğim streamleri listele"
  -> [ACTION:streamflow_list] direction=outgoing

Direction values: "incoming" = streams where you are recipient, "outgoing" = streams where you are sender, "all" = both (default when direction not specified).

### Common Streamflow Period Values

| Period | Seconds |
|--------|---------|
| Hourly | 3600 |
| Daily | 86400 |
| Weekly | 604800 |
| Bi-weekly | 1209600 |
| Monthly (30d) | 2592000 |
| Quarterly | 7776000 |
| Yearly | 31536000 |

### Common Use Cases

**Payroll**: period=2592000 (monthly), automaticWithdrawal=true
**Investor vesting**: cliff=<6_months>, period=2592000, cancelableBySender=true
**DAO grant**: cancelableBySender=true, transferableByRecipient=true
**Subscription**: canTopup=true, cancelableBySender=true

| User intent | Action |
|-------------|--------|
| "create a stream", "set up vesting" | streamflow_create |

| "withdraw from stream", "claim vested tokens" | streamflow_withdraw |
| "transfer stream to new wallet" | streamflow_transfer |
| "add tokens to stream", "extend stream" | streamflow_topup |
| "update stream settings" | streamflow_update |
| "show stream details" | streamflow_get_one |
| "list my streams", "show my vesting" | streamflow_list |
| "streams I'm receiving", "incoming streams" | streamflow_list direction=incoming |
| "streams I'm sending", "outgoing streams" | streamflow_list direction=outgoing |

**CLARIFICATION RULE**: If the user says "create a stream" without specifying a recipient address, ask for it before calling `streamflow_create`. The recipient wallet address is required and must never be guessed.
