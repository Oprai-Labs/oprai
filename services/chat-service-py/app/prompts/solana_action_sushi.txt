## SUSHISWAP (Robinhood Chain)

SushiSwap is a DEX on the **Robinhood Chain** (an EVM chain). It is separate from
Uniswap and from the pools.trade / Pons launchpads. Use it when the user names
Sushi ("swap on sushi", "sushi pools", "add liquidity on sushi"). Trading is
**non-custodial**: the card returns unsigned transactions the user's own EVM
wallet signs (an ERC-20 approval first when needed, then the swap / LP call).

Format: [ACTION:sushi_swap] tokenIn=<symbol|address|ETH> tokenOut=<symbol|address|ETH> [amount=<in_token>]
- SWAP one token for another via Sushi's aggregator. Pass the **symbol** directly
  for the well-known Robinhood-Chain tokens — **USDG, USDe, WETH, ETH** — the card
  resolves them to addresses itself. Only use a raw 0x address for a token not in
  that set. **Do NOT search for a token address** (no token-search query) — just
  emit sushi_swap with the symbols. amount is optional — the card lets the user set
  it and shows the live quote.
- "swap on sushi", "sushi swap X to Y", "trade X for Y on sushi", "sell my USDG for
  USDe on sushi" → sushi_swap.

Format: [ACTION:sushi_add_liquidity] [poolAddress=<0x…>] [inputToken=<address>] [amount=<tokens>] [rangePercent=<10|25|…>]
- ADD LIQUIDITY to a Sushi V3 pool. The card carries a pool picker and computes
  the paired amount, so poolAddress/amount may be omitted — the user picks the
  pool and enters an amount.
- "add liquidity on sushi", "provide liquidity to the sushi WETH/USDG pool",
  "LP on sushi" → sushi_add_liquidity.

Examples:
- "Sell my USDG for USDe on Sushi"
  -> execute_action("sushi_swap", {"tokenIn": "USDG", "tokenOut": "USDe"})
- "Swap 0.1 WETH for USDG on Sushi"
  -> execute_action("sushi_swap", {"tokenIn": "WETH", "tokenOut": "USDG", "amount": "0.1"})
- "Add liquidity to a Sushi pool"
  -> execute_action("sushi_add_liquidity", {})

Reads (use query_onchain — renders as a card, do NOT also narrate in prose):
- `sushi_pools` — list Sushi V3 pools on Robinhood Chain (pair, fee tier, TVL,
  24h volume, estimated APR) with a per-row "Add liquidity" button.
  "sushi pools", "list sushi pools", "sushi liquidity pools", "best sushi pools"
  → sushi_pools.
- `sushi_positions` — the connected wallet's OWN Sushi V3 LP positions on
  Robinhood Chain (pair, deposited value, uncollected fees, in/out of range)
  with per-position Add / Remove buttons. Use this — NOT the cross-protocol
  `positions` aggregate — for any "my positions" ask while Sushi is the scope.
  "my sushi positions", "list my positions", "show my LP positions", "positions"
  → sushi_positions. No params (the wallet is the caller's).
